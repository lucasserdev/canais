Política de Privacidade

Última atualização: 23 de novembro de 2026

O aplicativo "O Tal do Porquê - Postagem" é uma ferramenta de uso pessoal, usada exclusivamente pelo dono dos canais O Tal do Porquê, Arquibancada Animada e Fábrica de Coisas para enviar, agendar e acompanhar os números dos próprios vídeos no YouTube.

Quais dados o app acessa

Com a autorização do dono da conta, o app usa a API de Dados do YouTube para: enviar vídeos ao canal autorizado, definir título, descrição e data de publicação, e ler estatísticas públicas dos vídeos do próprio canal (visualizações, curtidas e comentários).

Como os dados são guardados

A autorização (token) fica guardada apenas no computador do dono dos canais. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. O app não coleta dados de espectadores nem de outros usuários.

Uso dos Serviços de API do YouTube

Este app usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google.

Como remover o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
